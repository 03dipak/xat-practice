================================================================================
STANDING RULES THAT APPLY TO EVERY ITEM ABOVE
================================================================================

- **Write the WRONG input first.** A check that has only ever seen a true statement
  is untested. Each item above names its falsifying input where one exists.
- **A check that fires on correct code is worse than no check.** Three times now a
  grep matched a docstring or a moved field. Prefer `ast` over text search.
- **Never hardcode a count in prose.** It goes stale within a day; the build does not
  notice.
- **`ruff` passing is not a build.** A deleted name imported AND USED is invisible to
  it. Run the import.
- **Gate per lesson.** A pool of lessons is not a paper (D23).
- **Never hand G11 a level-filtered drill** (D26).
- **Percentile claims name their strata or are `UNMEASURED`.**
- **A right default is not neutral.** The blank penalty bug cost no time to find and
  would have cost a learner real marks.
